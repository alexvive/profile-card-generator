# Profile Card Generator ✨

Create beautiful, professional profile cards for your digital identity in seconds.

Perfect for personal websites, portfolios, LinkedIn, resumes, and digital business cards.

![Preview](preview.png)

## 🚀 Features

- Real-time live preview
- Custom name, title, bio and contact information
- Upload your own profile photo
- Background and color customization
- Download as high-quality **PNG**
- Print as **PDF** directly from browser
- Clean, modern and responsive design

## How to Use

1. Open `profile-card-showcase.html`
2. Fill in your information and customize the card
3. Download PNG or print it

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
